1/ Most small businesses exploring AI automation spend longer evaluating tools than it takes to run a first project. The bottleneck is almost never the technology. ↓

2/ "AI automation" covers a wide range: basic text processing with existing tools ($50-500/mo) all the way to custom agents ($20-80k to build). Most small businesses have a viable first project in tier one or two.

3/ The right starting question is not "which AI should we use?" It's: which workflow, currently done by a person, could be done more reliably or at lower cost by an AI model?

4/ 2026 cost reality:
- Existing AI tools: $50-500/month
- Custom integration: $5-25k to build, 4-12 weeks
- Custom agent: $20-80k to build, 8-20 weeks
- Ongoing maintenance: $500-2k/month (the most underestimated line item)

5/ The most common failure mode: automating a workflow that wasn't clearly defined to begin with. If the team handles a task inconsistently today, the AI will too. At higher volume. Harder to catch.

6/ A good first project:
- Narrow scope with written handling rules
- Output you can verify correct or wrong
- Runs frequently enough for feedback within weeks
- Errors catchable before causing downstream harm
