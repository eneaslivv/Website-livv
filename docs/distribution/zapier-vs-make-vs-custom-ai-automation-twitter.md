1/ Zapier at 150,000 tasks/month: $18,000/year. Make at the same volume: ~$1,800/year. Custom code after a one-time build: $5 to $600/month. The numbers are that far apart. ↓

2/ How Zapier prices: each action step in a Zap = one task. A 3-step Zap on one record = 3 tasks. At 150k tasks/month, you're at ~$1,500/month. That's $18,000/year just for the subscription.

3/ Make prices by operations, not tasks. At 150k operations/month, Make runs ~$150/month. Same volume, same type of work. That 10x price gap is real and most people haven't done the math.

4/ The underrated risk: both platforms fail silently. A Zap hits a bad data format, logs the error, keeps going. If nobody watches the log, CRM records miss syncs, invoices don't send. You find out from a symptom, not an alert.

5/ Both have native AI steps. Both are shallow. You call a model and get text back. Dynamic prompts? Structured output you can branch on? Both require serious workarounds. That's where the hybrid pattern becomes practical.

6/ The hybrid: Zapier or Make handles data routing between apps. A custom webhook endpoint handles AI reasoning and structured output parsing. Build cost: $2k-$8k. Hosting: $5-$30/month. Existing workflows stay as-is.
