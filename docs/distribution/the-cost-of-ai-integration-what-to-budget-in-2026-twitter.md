1/ Most AI integration budgets undercount by 5-20x. The API rate card is the smallest line item in year one. ↓

2/ A complete AI integration budget has 4 layers:
- Model API (usage-based, per token)
- SaaS tooling (subscriptions)
- Development work (one-time build + future additions)
- Ongoing operations (hosting, maintenance, model updates)

3/ Development is 80-90% of year-one spend. That number doesn't appear until a quote arrives. The API bill surprises no one. The dev cost consistently does.

4/ First-year totals by integration type:
- Simple AI feature: $14K-$49K
- Chatbot with RAG: $32K-$108K
- Document processing: $43K-$152K
- AI agent workflow: $84K-$270K

5/ The API alone runs $20-$500/month for most integrations. A chatbot handling 10K conversations/month costs ~$40-$150/month on a mid-tier model. The development work to build it costs $20K-$60K.

6/ RAG adds $50-$300/month for vector DB hosting plus $8K-$25K in additional development. Fine-tuning costs $5K-$30K per training run and repeats whenever source data changes significantly.

7/ If scope is uncertain, phase it. POC with real data: $5K-$15K over 4-6 weeks. Production build after the POC validates value: $20K-$60K additional.
