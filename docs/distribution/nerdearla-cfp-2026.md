## Elevator pitch (~300 caracteres)

El 80% de los proyectos de IA muere entre el demo y producción. Operamos 5
productos con IA en producción (POS gastronómico, legaltech, un PM agent
sobre la API de Claude) para pymes reales de Argentina. Esta charla es el
post-mortem honesto: qué funciona, qué se rompe y qué cuesta de verdad.

## Descripción / abstract

Todos vimos demos espectaculares de IA. Casi nadie muestra qué pasa seis
meses después, cuando el bot atiende clientes reales un sábado a la noche y
la API cambió dos veces.

LIVV es un estudio chico de Buenos Aires que mantiene cinco productos con
IA en producción: un sistema para gastronomía, uno para estudios jurídicos,
un agente de gestión de proyectos construido sobre la API de Claude, y
automatizaciones operando para pymes argentinas. Esta charla es el
post-mortem honesto de ese recorrido:

- Qué automatizaciones generan retorno real en una pyme argentina (y
  cuáles son teatro).
- La decisión no-code vs código: cuándo n8n/Make alcanzan y cuándo
  necesitás un agente a medida, con números reales de costo.
- Por qué el diseño de producto importa más que el modelo: la diferencia
  entre IA que se adopta e IA que se abandona está en la interfaz.
- Fallas reales: automatizaciones que se rompen en silencio, alucinaciones
  frente a clientes, y cómo armamos el monitoreo después de quemarnos.
- Cuánto cuesta de verdad operar esto: tokens, mantenimiento, y el precio
  que una pyme puede pagar (con números públicos).

Sin slides de McKinsey, sin "la IA va a cambiar todo". Casos concretos,
números reales y errores propios, desde un equipo que factura con esto
todos los meses.
