1/ A focused custom software build runs 16 to 28 weeks from discovery to production. Most founders are surprised by that range. The variance isn't development speed. ↓

2/ The 5 phases and approximate week ranges for a mid-sized MVP:
- Discovery: weeks 1-4
- Design: weeks 3-8 (overlaps with end of discovery)
- Development: weeks 8-22
- QA + user acceptance testing: weeks 20-24
- Post-launch stabilization: weeks 23-30

3/ Discovery determines everything downstream. A feature found during requirements costs 1x. The same feature discovered mid-development costs 1.5x to 2x, from the disruption to work already underway.

4/ Third-party integrations are the most unpredictable timeline variable. Stripe: 2 to 4 days. A legacy ERP with inconsistent API docs and a sandbox that doesn't match production: 2 to 3 weeks. The integration map from discovery is how you size this risk before the build starts.

5/ Budget 30 to 60 days of post-launch stabilization separately from the build estimate. Most software surfaces 5 to 15 bugs in week one from real users interacting with the system in ways QA didn't model.
