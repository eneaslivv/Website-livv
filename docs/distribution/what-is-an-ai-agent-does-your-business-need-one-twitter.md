1/ Most businesses asking about AI agents actually need a workflow automation. The tools cost different amounts, fail differently, and require different ongoing maintenance. Here's how to tell which one fits. ↓

2/ A working definition: an AI agent takes a goal, decides which actions to take, calls tools to execute them (APIs, databases, code runners), observes the results, and loops until the task is done. That loop is what separates it from a chatbot or a fixed workflow.

3/ Each tool fails differently. A chatbot fails visibly in the conversation. A workflow fails detectably at one step. An agent fails after several steps have already run, with downstream actions already taken before anyone notices the error.

4/ Cost in 2026:
- Chatbot: $20–500/mo SaaS or $5k–25k custom
- Workflow: $50–300/mo SaaS or $5k–20k custom
- Custom AI agent: $15k–$150k build + $0.01–$0.50/run inference
- SaaS agent platforms: $200–2,000/mo

5/ 5 questions before building an agent:
1. How variable is the input?
2. How many systems does the task cross?
3. What does a wrong action cost?
4. How many times per week does it run?
5. Who maintains it after launch?

6/ A 10-step agent chain at 95% per-step accuracy succeeds 60% of the time. Shorter chains with human review on high-stakes steps are more reliable in production than longer fully automated ones.
