1/ Most custom software projects go over budget in the same phase. Not build. Discovery, the phase that was supposed to prevent it. ↓

2/ Five phases in a well-run custom build: discovery, design, build, ship, maintain. A requirement settled in discovery costs little. The same requirement settled during build costs 2-4x more.

3/ Discovery: 2-4 weeks, $5,000-$15,000. Produces a scope document both sides can read independently and describe consistently. Skip it, and those decisions get made at build rates.

4/ Build costs: $20,000-$60,000 for a focused workflow app. $60,000-$150,000+ for complex integrations. Both ranges assume discovery and design produced stable specs before build began.

5/ Data migration during ship is the most underestimated line item. Looks like 2 days in the scope. Commonly takes a week on real production data. Add $2,000-$10,000 to budget for it.

6/ Maintenance is a real line item: $1,000-$4,000/month minimum. A system with no maintenance accumulates security exposure and compatibility problems over 2-3 years.
