1/ AI features built for the demo tend to die in production. The drop shows up in usage data around 8 weeks after launch: initial engagement, then a cliff. Here's what actually drives adoption. ↓

2/ Most AI features fail because the team built around what the model can do, not what users need to get done. The right question: which tasks are users doing repeatedly, and are those tasks slower or less accurate than they should be?

3/ Two conditions for adoption: 1) The task must repeat. 3 min saved on a task done 15x/day beats 20 min saved on a once-a-year task. 2) The model must be accurate enough that users form a positive expectation within the first two weeks of use.

4/ The demo runs on curated data with crafted prompts. The product runs on a user's actual inputs at scale. The interface problems that kill adoption -- correction mechanisms, failure handling, expectation-setting -- are invisible in a demo.

5/ Metrics that matter for AI features: - Correction rate above 40% on a task type: model isn't meeting expectations - Abandonment rate above 20%: interface design is failing - Week-four retention (not week-one engagement) is actual adoption

6/ Cost to add a well-scoped AI feature to an existing product: $8K-$25K to build. API costs: $50-$500/month at moderate volume; $2K-$10K/month at high volume. These numbers assume you selected the right task first.
